# Esil Study — сайт для тестов по дисциплинам

Статический сайт без сервера и сборки: откройте `index.html` или выложите папку на любой хостинг (GitHub Pages и т. п.).
Старые вопросы удалены — сайт стартует пустым, тесты вы добавляете сами через **компилятор**.

## Быстрый старт

1. Откройте `index.html` → «Зайти» → **🧩 Компилятор тестов**.
2. Вставьте текст с тегами (или перетащите `.txt` / `.docx`), введите название дисциплины.
3. Нажмите **💾 Добавить на сайт** — тест сразу появится на главной (хранится в вашем браузере).
4. Чтобы тест видели все посетители: **⬇ Скачать .js** → положить в `data/disciplines/`, дописать id в `data/manifest.js`, увеличить `DATA_VERSION` в `js/config.js`, выложить на хостинг.

> База данных на статическом хостинге не работает, поэтому тесты — это обычные файлы (`.js` / `.json`), которые делает компилятор.

## Формат сырого текста

```
<question>Текст вопроса
<variant>Правильный ответ        ← ПЕРВЫЙ вариант считается правильным
<variant>Неправильный
<variant>Неправильный
<question>Следующий вопрос       ← новый <question> после последнего <variant> = новый вопрос
<variant>…
```

* Теги можно писать и на отдельных строках, и подряд в одной строке; регистр не важен.
* Вопрос и варианты могут переноситься на несколько строк — строки склеятся.
* **Несколько правильных ответов:** в компиляторе поставьте «Сколько первых вариантов считать правильными» = 2 (или больше) — или пометьте нужные варианты тегом `<right>` вместо `<variant>`.
* Из `.docx` читается весь текст абзацев (работает прямо в браузере). Старый `.doc` не поддерживается — сохраните как `.docx`.
* Компилятор показывает замечания: вопрос без вариантов, с одним вариантом, пустой текст и т. п. — такие вопросы пропускаются.

Примеры: `examples/sample.txt` (исходник), `examples/sample.json` (результат), `examples/psychodiagnostics.js` (файл для `data/disciplines/`).

## Как проходить тест

Экран настройки: количество вопросов (20 / 40 / 80 / 160 / все / своё число), таймер, режим экзамена.

| Режим | Поведение |
|---|---|
| Обычный, один правильный ответ | Ответ проверяется **сразу** после клика по варианту, без кнопки подтверждения. |
| Обычный, несколько правильных | Отмечаете варианты и жмёте **«Подтвердить ответ»** (или Enter). Засчитывается только полное совпадение. |
| 🎓 **Настоящий экзамен** (галочка перед началом) | Правильные/неправильные ответы **не показываются**; ответы можно менять сколько угодно (повторный клик снимает выбор), пока не нажмёте «Завершить экзамен». В конце — процент, время и разбор **всех** вопросов: где верно, где нет, какой ответ был правильным. |
| ⏱️ Таймер (в любом режиме) | 5–60 мин (до 120 для тестов от 160 вопросов). Подсказки помощника за 10, 5 и 1 минуту. В обычном режиме по истечении ответы блокируются, в экзамене тест завершается сам. |

Клавиши: `1–9` — выбрать вариант, `Enter` — подтвердить, `←/→` — листать.

```

esil-600x369.png     фон
js/
  config.js   настройки и ВСЕ тексты интерфейса (таймер, пресеты, подписи)
  utils.js    el(), add(), shuffle(), slugify(), download()
  store.js    данные: файлы + localStorage + проверка + parseTagged() (разбор тегов)
  layout.js   шапка сайта (hot-bar)       theme.js   тёмная/светлая тема
  auth.js     флаг «вошёл» (НЕ защита)    assistant.js  помощник 🤖 (вид страницы теста)
  home.js     главная   quiz.js  движок теста   compiler.js  компилятор   admin.js  редактор

  manifest.js              список id дисциплин (сейчас пустой)

```

## ⚠ Что не менять

| Что | Почему |
|---|---|
| Порядок `<script>`: `config → utils → store → layout → theme → auth → (assistant) → скрипт страницы` | каждый файл использует предыдущие |
| `id="app"` (index), `id="quiz-wrapper"`, `id="categoryTitle"`, `id="quiz"` (quiz), `id="admin"`, `id="compiler"` | сюда JS рисует страницу |
| Ключи localStorage `isLoggedIn`, `theme`, `quiz.local.v1`, `ql_*` | сохраняются вход, тема, правки и вид страницы теста |
| Обёртка `(window.QUIZ_DATA = …).push({...})` в файлах дисциплин | по ней `store.js` находит дисциплину |
| `id` дисциплины = имя файла (латиница, цифры, `-`, `_`; регистр важен) | иначе файл не найдётся |
| Вывод через `textContent` / `el()` / `add()`, а не `innerHTML` и не `node.append(null)` | иначе `<`, `&` в вопросах ломают страницу, а `append` печатает «null» |
| CSS-классы, которые создаёт JS (`.answer .multi .selected .correct .wrong .answered .grid-question .timer-bar …`) | переименуете в CSS — переименуйте и в JS |

## Ограничения (честно)

* **Вход «Зайти» — не защита:** флаг в localStorage, а `data/*.js` скачиваются по прямой ссылке. Для приватных материалов нужен сервер.
* **«Добавить на сайт» хранит данные в браузере** (≈5 МБ). Очистили данные сайта — пропали. Делайте резервную копию в редакторе и публикуйте файлами в `data/`.
* После замены файлов в `data/` увеличьте `DATA_VERSION` в `js/config.js` (кэш браузера).
* Для публичной версии без редактора поставьте `ADMIN_ENABLED: false` (это скрытие, а не защита).
* Конспекты, колоды карточек и статистика из старого проекта (`deploy-…`) не переносились — в запросе были только дизайн, таймер, режимы и компилятор.
