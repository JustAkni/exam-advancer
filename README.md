# Exam-Advancer — сайт для тестов по дисциплинам

Статический сайт без сервера и сборки: откройте `index.html` или выложите папку на любой хостинг (GitHub Pages и т. п.).
Оформление — «школьный класс» в духе меню K-On! PSP: фон-кабинет, наклонная деревянная доска-пробка с записками, мягкий округлый шрифт.
Входа («Доступ») и паролей нет: открыл сайт — и всё работает. Есть **редактор** (`admin.html`) и **компилятор** (`compiler.html`). В комплекте одна тестовая дисциплина «Глюкоза» (10 вопросов) — удалите её, когда добавите свои (см. `data/manifest.js`).

В правом верхнем углу две кнопки: 🌙/☀️ — тема, 🕰️/🪵 — **старый красно-белый дизайн** ⇄ новый (выбор запоминается; функции те же).

## Быстрый старт

1. Откройте `index.html` → записка **🧩 Компилятор тестов** (править готовое и обмениваться файлами — **✏️ Редактор**).
2. Вставьте текст с тегами (или перетащите `.txt` / `.docx`), введите название дисциплины.
3. Нажмите **💾 Добавить на сайт** — тест сразу появится на главной (хранится в вашем браузере).
4. Чтобы тест видели все посетители: **⬇ Скачать дисциплину (.js)** → положить в `data/disciplines/`, дописать id в `data/manifest.js` (`window.QUIZ_FILES = ["id1", "id2"];`), увеличить `DATA_VERSION` в `js/config.js`, выложить на хостинг.

> База данных на статическом хостинге не работает, поэтому тесты — это обычные файлы (`.js` / `.json`), которые делает компилятор.

## Формат сырого текста

```
<question>Текст вопроса
<variant>Правильный ответ        ← ПЕРВЫЙ вариант считается правильным
<variant>Неправильный
<variant>Неправильный
<question>Следующий вопрос       ← новый <question> после последнего <variant> = новый вопрос
<variant>…
```

* Теги можно писать и на отдельных строках, и подряд в одной строке; регистр не важен.
* Вопрос и варианты могут переноситься на несколько строк — строки склеятся.
* **Несколько правильных ответов:** в компиляторе поставьте «Сколько первых вариантов считать правильными» = 2 (или больше) — или пометьте нужные варианты тегом `<right>` вместо `<variant>`.
* `.docx` читается прямо в браузере. Старый `.doc` не поддерживается — сохраните как `.docx` или `.txt`.
* Компилятор показывает замечания (вопрос без вариантов, с одним вариантом, пустой текст) — такие вопросы пропускаются.

Примеры: `examples/sample.txt` (исходник), `examples/sample.json` (результат), `examples/psychodiagnostics.js` (файл для `data/disciplines/`).

## Файлы: что такое .js и .json

| Файл | Что внутри | Для чего |
|---|---|---|
| **`.json`** | **все** ваши дисциплины сразу | резервная копия, перенос на другое устройство. Редактор → «Экспорт всех (.json)» / «Импорт (.json)» |
| **`.js`** | **одна** выбранная дисциплина | отправить другу, получить чужую, опубликовать для всех. Редактор → «Экспорт дисциплины (.js)» / «Импорт дисциплины (.js)» |

Почему именно `.js`, а не `.json`, для публикации: сайт открывается и без сервера (двойным кликом по `index.html`), а браузер **не разрешает** читать `.json` с диска, зато `.js` подключается обычным тегом `<script>`. Поэтому файл дисциплины в `data/disciplines/` — это `.js`. Импорт чужого `.js` безопасен: код **не выполняется**, файл разбирается как данные (если внутри что-то похожее на код — импорт откажется).

Если импортируемая дисциплина у вас уже есть, редактор спросит: **Заменить** / **Объединить** (добавить вопросы, повторы не добавятся) / **Копия** (сохранить рядом под новым id) / Отмена.

## Как проходить тест

Экран настройки: количество вопросов (20 / 40 / 80 / 160 / все / своё число), таймер, режим экзамена.

| Режим | Поведение |
|---|---|
| Обычный, один правильный ответ | Ответ проверяется **сразу** после клика, без кнопки подтверждения. |
| Обычный, несколько правильных | Отмечаете варианты и жмёте **«Подтвердить ответ»** (или Enter). Засчитывается только полное совпадение. |
| 🎓 **Настоящий экзамен** | Правильные/неправильные ответы не показываются, ответы можно менять до завершения (повторный клик снимает выбор). В конце — процент, время и разбор **всех** вопросов. |
| ⏱️ Таймер (в любом режиме) | 5–60 мин (до 120 для тестов от 160 вопросов). В обычном режиме по истечении ответы блокируются, в экзамене тест завершается сам. |

Клавиши: `1–9` — выбрать вариант, `Enter` — подтвердить, `←/→` — листать.

## Оформление и анимации

* **Фоны:** `images/classroom1.png` — главное меню, компилятор и редактор, `images/classroom2.png` — страница теста. Оригиналы (736 px) увеличены в 3 раза нейросетью (EDSR ×3) до 2208 px — картинка заметно чётче. Можно заменить своими (те же имена, лучше от 1600 px по ширине).
* **Вид меню:** записка «🎛 Вид меню» (только в новом дизайне) — сторона (снизу / сверху / слева / справа), направление кнопок (горизонтально / вертикально), наклон (ровно, 10°, 16°, 20°; на телефоне наклон автоматически меньше). Выбор запоминается в браузере. В горизонтальном ряду записки листаются колесом мыши или свайпом.
* **Записки** дисциплин, сохранённых в браузере, удаляются крестиком ✕ (файловые из `data/` — только удалением файла; в редакторе — «Сбросить правки»).
* **Старый дизайн:** шапка со ссылками, белые карточки с красной полосой, список дисциплин вместо доски. Цвета — блок «КЛАССИЧЕСКИЙ ДИЗАЙН» в конце `css/style.css` (переменные `--red`, `--red-dark`).
* **Анимации:** панель выезжает, записки «падают» по очереди, плашки заголовков выезжают сбоку, новый вопрос появляется «листком». Переход между страницами — деревянный «занавес» по диагонали (`js/transition.js`). Если в системе включено «уменьшить движение», анимации отключаются.
* **Цвета и шрифт:** переменные в начале `css/style.css` (день и `[data-theme="dark"]` — «вечер»); шрифт M PLUS Rounded 1c лежит локально в `fonts/` (лицензия OFL), интернет не нужен.

## ⚠ Что не менять

| Что | Почему |
|---|---|
| Порядок `<script>`: `config → utils → store → layout → theme → transition → (assistant) → скрипт страницы` | каждый файл использует предыдущие |
| `id="app"` (index), `id="quiz-wrapper"`, `id="categoryTitle"`, `id="quiz"` (quiz), `id="compiler"`, `id="admin"` | сюда JS рисует страницу |
| Скрипт в `<head>` каждой страницы (тема, дизайн, флаг `pt`) | применяет тему до отрисовки и включает «занавес» без вспышки |
| Ключи localStorage `theme`, `design`, `quiz.local.v1`, `menu.dock.v1`, `ql_*` | тема, дизайн, сохранённые тесты, вид меню, вид страницы теста |
| Обёртка `(window.QUIZ_DATA = …).push({...})` в файлах дисциплин | по ней `store.js` находит дисциплину |
| `id` дисциплины = имя файла (латиница, цифры, `-`, `_`; регистр важен) | иначе файл не найдётся |
| Вывод через `textContent` / `el()` / `add()`, а не `innerHTML` и не `node.append(null)` | иначе `<`, `&` в вопросах ломают страницу, а `append` печатает «null» |
| CSS-классы, которые создаёт JS (`.dock .note .answer .grid-question .timer-bar .curtain …`) | переименуете в CSS — переименуйте и в JS |

## Ограничения (честно)

* **Данные не защищены:** `data/*.js` скачиваются по прямой ссылке. Для приватных материалов нужен сервер.
* **«Добавить на сайт» хранит данные в браузере** (≈5 МБ). Очистили данные сайта — пропали. Делайте резервную копию (редактор → «Экспорт всех (.json)») и публикуйте файлами в `data/`.
* После замены файлов в `data/` увеличьте `DATA_VERSION` в `js/config.js` (кэш браузера).
* Конспекты, колоды карточек и статистика из старого проекта не переносились.
